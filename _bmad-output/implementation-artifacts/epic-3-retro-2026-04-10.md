## Challenges

### 1. Error-Path / Defensive Coding Gaps Found in Review (Recurring)

Code reviews found missing STATE guards or error-path issues in 3 stories:
- Story 3.1: `;` crashes outside a definition (uninitialised `colon_smudge_addr`)
- Story 3.2: DOES> missing STATE guard (compile-mode check)
- Story 3.5: POSTPONE not-found path used ABORT instead of COMP-ERROR, leaving corrupted dictionary state

All are variations of "user does something wrong" paths getting less attention on first pass.

**Resolution:** All fixed during adversarial code review. This is the system working as designed — reviews MUST find things.

### 2. LEAVE Chain Design Broke Under Nesting (Story 3.4)

Original spec had LEAVE chain on the compile-time data stack. Broke when LEAVE appeared inside IF/THEN because the stack had IF's forward-ref on top. Interpreter hung.

**Resolution:** Redesigned to use dedicated `leave_chain_head` assembly cell with DO/LOOP saving/restoring outer value. Cleaner and more robust than original design.

### 3. POSTPONE Semantics Initially Swapped (Story 3.5)

IMMEDIATE and non-IMMEDIATE compilation paths were reversed. Caught during development by checking the ANS standard.

**Resolution:** Corrected per ANS. Team self-corrected without project-lead intervention — evidence of standards compliance commitment from Epic 2.

### 4. Over-Exuberant ANS Spec Reading on `."` (Story 3.5)

`."` implementation was overly strict based on spec wording. Found and fixed in a timely fashion.

## Significant Discovery: Epic 4 Scope Change

During the retrospective, the project lead identified that Epic 4 needs additional scope:
1. **Labels (including forward labels)** — manual byte-counting for jumps is error-prone
2. **Data definition words (DB, DW, DS, EQU)** — needed for lookup tables and constants in CODE words
3. **Startup banner** — `AntForth v1.00 (c) ant.org 2026` with free memory display

**Revised Epic 4 structure (2 stories → 5 stories):**

| # | Story | Scope |
|---|-------|-------|
| 4.0 | Startup Banner | Cold-start banner with version, copyright, free memory |
| 4.1 | CODE Word Framework & Basic Instructions | CODE/END-CODE, NEXT,, basic register ops, push/pop |
| 4.2 | Labels & Data Definition Words | Forward/backward labels, DB, DW, DS, EQU |
| 4.3 | Basic Z80 Opcodes | Core instruction set — loads, arithmetic, jumps, calls |
| 4.4 | Extended Z80 Opcodes | CB-prefixed (bit/rotate/shift), DD/FD-prefixed (IX/IY), I/O |

**Rationale:** Labels and data defs are foundational and should be available before filling out the instruction set. Splitting opcodes into basic/extended separates single-byte encoding from prefix-based encoding.

**Action Required:** Update epics.md before Epic 4 kickoff.
