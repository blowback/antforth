## What went well

- **The reuse ladder was the whole design, and it held.** `MUTEX = 1 SEMAPHORE`,
  `LOCK = WAIT` verbatim, `UNLOCK = 1 SWAP !`, `MAILBOX = CREATE + three commas`,
  `POST`/`FETCH` = `WAIT`/`SIGNAL` composed over the mailbox structure. The only genuinely
  new code across the whole epic was three threaded bodies in 26.3. Every word took the
  `DEFWORD` route, so the PAUSE register contract (DE=IP preserved) held **by
  construction** — no raw Z80, no register-exposure risk.
- **AI-25-4 front-loading worked exactly as intended.** The standing multitasker contract
  (DE=IP, per-task `sp_base`, the `TASK ( -- task )` handle footgun, `AGAIN`-undefined) was
  pasted into all three story Dev Notes up front. The footguns that bit Epic 25 repeatedly
  **did not recur once** in Epic 26 development.
- **AI-25-3 landed as a real, probed AC.** 26.1's `sem-wait-starves-ring-alive` is a named
  verdict contrasting cooperative-friendly starvation (ring stays live, peer + operator
  keep advancing) against Story 25.7's reset-required non-yielding stall. Inherited by
  mutex and mailbox.
- **Byte estimates near-perfect.** The B.2 per-word itemisation method (header base
  re-derived from 26.1's measured +80 B) predicted 26.3 to the byte (+103 est / +103
  actual) and 26.2 exactly (+58/+58).
- **Test discipline caught fixture bugs, not feature bugs.** All three debug-log entries
  were probe/fixture errors (uninitialised `WBUF`; DEPTH accounting; the `w_FETCH` asm
  label colliding with `@`'s internal label) — the primitives themselves were correct
  first-try. Runtime-computed witnesses (the 23.2 false-green defence) used throughout; a
  neutered-`LOCK` discrimination test in the 26.2 review proved the exclusion probe is a
  genuine witness, not a false-green.

## What was hard / recurring

1. **The operator-context wedge, restated three times.** A blocking `WAIT`/`LOCK`/`FETCH`
   run at the REPL prompt hard-wedges the machine (the operator is the keyboard-reader and
   is break-exempt; even `Ctrl-\` cannot recover). Correct feature, sharp footgun — now the
   dominant caveat of the whole coordination surface (`project_operator_wait_wedge`).
   Documented in each story and in `docs/phase6-multitasker.md`.
2. **Emulator-vs-silicon gap, again** (the defining Phase-6 tension). Wall-clock interleave
   and prompt-responsiveness are provable only on hardware; iz-cpm asserts structure only.
   Every story stated the split honestly.
3. **HW UAT surfaced a doc defect the emulator structurally couldn't (26.3):** a bare
   `4 0 DO mb FETCH . LOOP` typed at the operator prompt throws `-14` (compile-only word) —
   `DO`/`LOOP`/`I` must live inside a `: … ;`. The emulator probe hid it because its
   consumer loop was already inside a colon word. Fixed the doc example + added the caveat.
   A catch only hardware could produce.
4. **TCB budget ceiling is real.** The ~2 KB-below-`$8000` TCB pool caps probes at ~2
   forever-tasks (26.1 hit the `-8` dictionary-overflow guard at 4). Every probe was
   structured around it — background producer/writer + a bounded operator `DO` loop.

## Known limitations / carried debt (net, epic-end)

- **Operator-context blocking wedge** (`WAIT`/`LOCK`/`POST`/`FETCH` at the REPL prompt with
  no background unblocker) = reset-required. Documented-not-guarded by design; blocking
  waits belong in background `TASK`s (`project_operator_wait_wedge`).
- **Non-atomic by design.** Correctness rests on the cooperative single-thread-except-ISR
  model (the 64 Hz ISR touches only `TICKS`); safe because no `PAUSE` sits between a count
  check and its store. Would be **wrong** to add interrupt masking or a mid-window `PAUSE`.
- **Single-slot mailbox only.** Bounded-buffer-N (ring buffer, `empty=N`) is deferred
  future work — `empty=N` is free, add ring + head/tail + power-of-2 mask; ship as a
  separate `MAILBOX-N`/`QUEUE`, not a change to `MAILBOX` (`project_multislot_mailbox_future`).
- **TCB pool ceiling** (~2 KB below `$8000`, ~a handful of tasks). Inherent to the
  fixed-memory scheduler; documented across Epic 25/26 probes.
