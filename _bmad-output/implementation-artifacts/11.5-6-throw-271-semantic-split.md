# Story 11.5.6: `-271` semantic split

Status: done

## Story

As a Forth user,
I want `THROW_ASM_RANGE = -271` split so that `+D`'s 8-bit displacement out-of-range raises one code (`-271 THROW_ASM_DISP_RANGE`, retained EQU value) and `BIT,/RES,/SET,`'s bit-number-must-be-0..7 guard raises a distinct new code (`-272 THROW_ASM_BIT_RANGE`),
so that the user diagnostic identifies which assembler check failed instead of collapsing two structurally-different conditions onto a single generic `range` message — closes the Story 11.6 F4 LOW-deferred finding (`docs/throw-codes.md:217-229` "Note on -271 semantic collapse").
